# Canonical fixed80 training source

This directory exposes the original frozen fixed80 training and ablation suite
for browsing. Existing implementation files are copied without algorithm edits.
The same files are retained in the original source archive and provenance index.

Run `run_pipeline.py` with an explicit `--data-root` and a new `--output-root`.
See the repository-level DATA.md and REPRODUCIBILITY.md before running.
The full suite has not been retrained for this release.
