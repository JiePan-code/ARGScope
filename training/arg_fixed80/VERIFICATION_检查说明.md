# 交付前检查

本包在用户本机的 RTX 5060、`dnabert2_5060` Python 环境进行检查。

- 原始 26,878 条 Protein / DNA embedding 均可读取，维度分别为 1280 / 768；包含全部 22,870 个保留样本。
- 固定划分文件、标签、ID 集合和序列分组指纹通过核对；实际 train / validation / test 为 14,636 / 3,660 / 4,574。
- 五个模型核心实现与上一套代码逐字节相同；没有更改架构、正常模式训练预算、损失定义或选择逻辑。共享划分接口改为读取固定名单。
- 14 个阶段（两套上游三步流程 + 八个 Student）在隔离目录完成一轮衔接测试，包括两个 w/o Transfer 分支。此检查仅测试接口可运行，不能代表正式训练完成或正式精度。
- 独立重新计算原始 embedding 的 model-train 均值/标准差，与两套 Fusion 及八个 Student 实际保存的值核对一致。
- 独立重算 model-train raw prototypes，与保存结果一致；w/o Graph 两种 Student 确实使用这些 raw prototypes。
- w/o Gate 的实际 gate 权重全部为 0.5；w/o Transfer 的 Teacher epoch 为 0，五个迁移系数全为 0。
- 每种模态的三个消融与新 Full 的配置及 Student 参数形状相同，只有所消融项不同。
- 所有八个预测文件均严格覆盖同样的 4,574 个 test ID，真值一致；保存的实际划分与固定名单一致。
- 短测试的结果只用于检查汇总接口，不随代码作为正式实验结果交付。机器可读检查记录见 `SMOKE_VERIFICATION.json`。

代码检查中特别保留了旧实验，禁止覆盖已有阶段目录，并增加旧划分、错配上游及改动文件的拒绝检查。正式训练由用户运行；能否取得更高指标由新实验决定，不预设 Full 必须胜过消融。
